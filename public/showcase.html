Research prototype · DevFest Mumbai 2026

A home visit, one question at a time, with both hands free.

Community health workers often run a visit checklist while holding a newborn, a scale or a thermometer. Dastak puts exactly one question on a 600 × 600 head-worn display, takes the answer from a four-way pad and a confirm gesture, and follows a fixed, reviewable protocol to the next question.

Try the wearable demo Inspect the source

Not clinically validated. Not deployed in care. Not affiliated with or endorsed by Meta. All protocol content is draft or placeholder and awaits qualified clinical review.

Who it is for

Frontline workers who visit households on a schedule, such as India's ASHA workers doing home-based newborn care. During a visit their hands and attention belong to the family, not to a form.

What it does

  • Runs a visit protocol written as data, one frame per question.
  • Shows referral flags in place, counts them once, and lists them at the end.
  • Saves progress on the device after every answer, so an interrupted visit can resume.
  • Recalls only what this worker recorded last time for the same household and protocol.

Architecture

The visit workflow is a deterministic interpreter over versioned protocol data. Optional AI exists only in separate, nonclinical planning and review pages.

Protocol as data

Five frame types: yes/no, choice, count, range, info. Transitions are explicit IDs; thresholds are explicit comparisons. Every protocol carries a lifecycle status and provenance.

One source of truth

The app's bundled registry is generated from protocols/*.json. The build fails on invalid protocols, unreachable steps, cycles, off-grid defaults, or any drift between source and bundle.

Same engine everywhere

The interpreter is a pure module. The browser app, the validator and the test suite all execute the same code, so what is tested is what runs.

The interaction

Below is the actual wearable app, not a recording. Click inside it, then use the arrow keys and Enter. Esc goes back. On a phone, tap an option to choose it.

  1. Start frame. ← → picks the household, ↑ ↓ the visit type, Enter begins.
  2. One question. Each frame asks one thing. Numbers start at the protocol's default and stay within its range.
  3. Referral flags. A flag frame shows the protocol's own referral text and is counted exactly once.
  4. Interruption. Reload mid-visit: the app offers to resume with every earlier answer intact.
  5. Completion. Only a visit that reaches the protocol's end is called complete. Anything else says it is not.

The demo shares this browser's storage with the app at /. Use Settings → Delete data on this device to clear it.

Why generative AI is not in the visit path

A visit protocol has to give the same next question for the same answer, every time, in a form a clinician can read line by line and sign off. A language model offers none of those properties: its output can vary, it can invent plausible guidance, and its reasoning cannot be reviewed in advance.

So the visit path contains no model, no network call and no generated text. Every prompt, threshold and referral line on screen comes from a versioned protocol file whose source and review state are recorded. AI appears only in the separate planner and review pages, where it can reorder IDs or describe counts, and where every output is checked and replaceable by a fixed rule.

Limitations and safety

  • Dastak does not diagnose and must not be used to make care decisions. Its protocols are unreviewed drafts or placeholders.
  • Thresholds such as 38.5 °C or 140 mmHg are structural test values, not clinical guidance.
  • Data on the device is not encrypted, and anyone with the device's browser can read it.
  • The yes/no frame highlights "Yes" first, carried over from the original prototype. Whether any default is safe needs testing with real workers.
  • Behaviour on Meta's hardware, including how gestures map to keys and to Back, has not been verified.
  • The AI output filter is a coarse word list. It reduces risk; it does not guarantee nonclinical output.
